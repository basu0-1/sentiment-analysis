# 🧠 AI Personal Diary with Sentiment Analysis

## 📌 Overview
This project is an AI-powered personal diary application that analyzes user-written entries and predicts the emotional sentiment behind them.

Users can write their daily thoughts, and the system automatically detects whether the mood is:
- 😊 Positive  
- 😐 Neutral  
- 😢 Negative  

The app also stores entries and provides mood analytics over time.

---

## 🚀 Features
- ✍️ Write and save diary entries  
- 🧠 Sentiment analysis using Machine Learning  
- 📊 Mood analytics with visual charts  
- 📜 History of past entries  
- 🎛️ Interactive Streamlit UI  

---

## 🧠 Machine Learning Details
- Model: Logistic Regression  
- Text Processing: TF-IDF Vectorization  
- Dataset: IMDb Reviews Dataset  
- Accuracy: ~85–90%  

---
